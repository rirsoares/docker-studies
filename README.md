# 🐳 Docker do Zero — Material de Estudo e Ensino

Repositório de estudos sobre Docker, construído módulo a módulo, com o objetivo de
servir como material didático de referência — para estudo, treinamentos e projetos.

## Como este repositório está organizado

```
docker-studies/
├── README.md                  ← você está aqui (plano do curso)
├── COMO-PUBLICAR-NO-GITHUB.md ← guia para subir este repo
├── modulo-01-fundamentos/
│   ├── apostila.md            ← teoria explicada de forma didática
│   ├── exercicios.md          ← lista de exercícios
│   ├── gabarito.md            ← respostas comentadas
│   └── exemplos/              ← arquivos práticos para executar
├── modulo-02-imagens-e-dockerfile/
├── modulo-03-volumes-e-dados/
├── modulo-04-redes/
├── modulo-05-docker-compose/
└── slides/                    ← apresentações para aula (geradas por módulo)
```

## Plano do curso

| Módulo | Tema | Status |
|--------|------|--------|
| 1 | Fundamentos: o que é Docker, containers vs VMs, primeiros comandos | ✅ |
| 2 | Imagens e Dockerfile: criando suas próprias imagens | ⬜ |
| 3 | Volumes e persistência de dados | ⬜ |
| 4 | Redes: comunicação entre containers | ⬜ |
| 5 | Docker Compose: aplicações com múltiplos containers | ⬜ |
| 6 | Boas práticas e projeto final | ⬜ |

## Pré-requisitos

- Noções básicas de terminal (revisado no módulo 1)
- Computador com Windows 10/11, macOS ou Linux
- Nenhuma experiência prévia com Docker é necessária

## Como estudar

1. Leia a `apostila.md` do módulo
2. Execute os `exemplos/` no seu computador
3. Faça os `exercicios.md` sem olhar o gabarito
4. Confira o `gabarito.md` e revise o que errou
